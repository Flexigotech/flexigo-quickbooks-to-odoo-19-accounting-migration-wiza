# flexigo_quickbooks_to_odoo_19_accounting_migration_wiza

Wizard-driven toolkit for QuickBooks → Odoo 19 cutover migrations

**Version:** 19.0.1.0.2
**Target Odoo:** 19.0
**License:** OPL-1
**Author:** FlexigoTech ([flexigotech.com](https://flexigotech.com))

## Installation

This module is distributed via the **Odoo Apps Store** and **Odoo.sh** for FlexigoTech customers.
For source installation, place the `flexigo_quickbooks_to_odoo_19_accounting_migration_wiza/` folder into your Odoo addons path and install via Apps menu.
