# QuickBooks to Odoo 19 Accounting Migration Wizard — User Guide

Wizard-driven toolkit for QuickBooks → Odoo 19 cutover migrations

## Installation
1. Download the module and add it to your Odoo addons path (or deploy via Odoo.sh).
2. Update the Apps list and install the module from the Apps menu.
3. Open the module menu from the main navigation to get started.

## Getting started
The module provides the following capabilities:
- Functional Requirements
- Monetization tier
- 1. Context and Problem
- 1.1 What is Happening Now (without the app)
- 1.2 Consequences of Doing Nothing (or doing it ad-hoc)
- 1.3 Source-System Context (QuickBooks, as of 2026)
- 1.4 Why Odoo-Native (vs external ETL)
- 2. Target Client and Users
- 2.1 Company Profile
- 2.2 User Roles
- 2.3 Primary Buyer & Decision Driver
- 3. Product Objectives
